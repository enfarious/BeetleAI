Settings

Controls when the agent compacts and how hard it trims, so long runs don't overflow (stall/timeout) or over-compact. Auto-fills from the model you pick via Fetch — match your model's num_ctx.
Optional. A stronger model Beetle consults via request_assist when it's stuck. Leave provider on "(disabled)" to turn it off.
Optional. Powers semantic recall and the search_codebase tool. Anthropic has no embeddings API — use Voyage or a local Ollama embed model. Leave provider on "(disabled)" to turn RAG off.
When on, each run automatically gets the top code matches for its task added to context (one embedding call per run) — in addition to the agent's search_codebase tool. Turn off to save tokens and rely on the tool alone.
When on, the index is incrementally refreshed in the background as each run starts (only changed files are re-embedded). Turn off for manual indexing — the index updates only when you click Reindex, avoiding the per-run file scan on large repos.
Once a provider is set and tested, build the index per-project from the Reindex button under the project selector.
